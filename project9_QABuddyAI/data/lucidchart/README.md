# lucidchart

Drop Lucidchart diagrams exported as text/description `.txt`/`.md` files
here (export the diagram's text content, not the image).

Ingested by `qabuddy/loaders/lucidchart_loader.py` (`source_type=lucidchart`).
Chunk size/overlap: 1000/150 chars.

Run `python ingest.py lucidchart` after adding files.
