# meeting_notes

Drop already-transcribed meeting notes here as `.txt`/`.md` files.
Audio/video recordings are **not** transcribed automatically in Phase 1 —
transcribe first, then drop the text here.

Ingested by `qabuddy/loaders/meeting_note_loader.py` (`source_type=meeting_note`).
Chunk size/overlap: 1000/150 chars.

Run `python ingest.py meeting_note` after adding files.
